退出

这个工具是什么

它把一份需求（文案、参考图、品牌）变成一份可交付的设计草案。注意：产出是 给设计师收尾的草案，不是最终成品。你的眼睛是唯一的质量标准：机器永远不替你判断"好不好看"。

完整流程（费用都标在按钮上）

  1. 录入品牌（每个品牌只做一次，免费）：在"录入品牌"页上传 VI 手册 PDF + Logo 文件，确认颜色和名称。做完后品牌会出现在生成页的下拉框里。
  2. 填写需求表单（免费）：选品牌、写文案、上传风格参考图。 点"开始"后系统先免费推导方案，不生成图。
  3. 付费前确认（3b）：系统列出它替你做的每一项假设，你可以修改（修改后免费重新推导）。 点"确认并生成"（约 $0.08）才真正花钱出图。不点确认就永远不收费。
  4. 用眼睛判断（5）：满意就定稿；不满意就写一条修改意见，系统免费重新推导， 新方案在它自己的确认页上再收费。
  5. 分层导出（6，可选）：把定稿画面拆成逐元素图层（透明 PNG + 白底 JPG，打包 zip）， 方便设计师在 PS 里继续加工。按图层数收费，约 $0.5，按钮上会先标明确切金额。

表单字段说明（哪些可以直接写中文）

字段怎么填
产出物类型自由中文，如"朋友圈海报""门店手举牌"。会作为画面主题参考，不会被画成文字。
渲染风格扁平插画（卡通/矢量感）或摄影质感（真实照片感），下拉选择。
尺寸如 60x40cm；中文写法也行：６０×４０厘米。
风格参考图必选。整体感觉以这张图为准，选一张接近理想效果的。
产品实拍图可选，最多 6 张。画面里会出现真实的产品（含印刷的标签、logo），不会瞎画。
用途自由中文，如"朋友圈推广""活动现场手举牌"。系统据此判断做营销物料还是活动道具。
画面上的文字每行一条，逐字呈现：画面上只会出现这些字，一个字都不会多。
设计要求必须遵守的指令，如"产品要写实，背景卡通"。

排队规则（很重要）

工具一次只能跑一个生成任务。如果点按钮时提示 a run is already in flight，说明有同事的任务正在跑：等一两分钟再点， 不要连点。右侧"最近的运行"列表能看到所有人的任务；刷新页面不会丢失任务， 网址会记住你正在看的那一个。

常见英文提示对照表

系统内部提示是英文的（工程约定）；对照如下：

英文提示意思
a run is already in flight (single-flight); wait有任务正在跑，等它结束再操作。
already confirmed; no second spend已经确认过了，不会重复收费（放心，连点不会多扣钱）。
already exporting/exported; no second spend导出已在进行或已完成，不会重复收费。
export needs a generated, judged image要先确认生成出图，才能导出图层。
upload too large: ... exceeds the ...MB cap上传的文件太大，压缩后再试。
brand asset not found ...品牌 Logo 文件缺失，联系管理员补齐素材。
Run failed / worker timed out ...本次运行失败或超时；看"最近的运行"重开一次，反复失败就联系管理员。
could not parse a WxH size ...尺寸没写明白；在确认页上直接选一个尺寸即可。

常见问题

画面上的字错了/多了怎么办？

在第 5 步写修改意见（免费重新推导），例如"标题只保留'守住钱袋子'五个字"。文字类问题通常一次调整就能解决。

Logo 画得不太对？

这是已知的弱项：AI 重绘 logo 有概率出错。两个办法：写修改意见重试；或用"分层导出"拿到分层文件， 让设计师把真 logo 文件贴上去（几分钟的事）。

刷新后页面空了？

点右侧"最近的运行"里你的任务即可恢复；或直接用带 #run_... 的完整网址。

页面一直转圈不动？

生成一般 1-2 分钟。超过 5 分钟仍无变化，刷新页面重新打开该任务；如果显示失败，重开一次即可， 反复失败请联系管理员。

品牌管理

导航栏的「品牌管理」页列出服务器上的全部品牌：可以修改名称、调整颜色角色、更换 logo（仅支持 PNG/JPG/WebP），也可以删除不需要的品牌（需要原样输入品牌 ID 确认；删除只移除品牌档案，素材文件保留）。 每个品牌都标明素材是否齐全：缺少 logo 的品牌出图时会被明确拒绝，先补齐素材或删除该品牌。

登录与权限（如果管理员开启了登录）

登录是白名单制：账号由管理员在服务器上创建，没有自助注册；忘记密码请管理员重新创建同名账号即可重设。 登录后导航栏右侧显示你的用户名，点「退出」注销。权限模型：你能看到自己录入的品牌、自己发起的任务， 以及所有未认领的共享内容（开启登录之前的历史品牌和任务没有所有者，对全团队可见）； 管理员能看到并管理全部内容，也可以在「品牌管理」页为品牌指定所有者。 打开页面直接跳到登录页 = 登录已开启；没有登录页 = 服务器未开启登录，一切照旧。
